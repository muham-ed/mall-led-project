# وصف المشروع — Mall LED Facade

## الهدف
تصميم واجهة خارجية لمول تجاري عصري مع دمج شاشات LED بشكل احترافي،
مع تصورات ثلاثية الأبعاد ومخططات توضيحية.

## العملة
كل المبالغ بالريال السعودي (SAR).

## المتطلبات الفنية الإلزامية
| العنصر | القيمة الدنيا |
|-------|---------------|
| سطوع الشاشة | 6,000 nit |
| معدل التحديث | 3,840 Hz |
| حماية IP | IP65 |
| نسبة التباين | 40,000:1 |
| وصول الصيانة | أمام وخلف |

## الالتزام القانوني (السعودية)
- مكتب استشاري معتمد إلزامي
- أقصى تغطية للواجهة: 80%
- أدنى ارتفاع للمبنى: 15 م
- الالتزام بـ SBC 301 و SBC 306
