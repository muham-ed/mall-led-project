# مشروع واجهة مول تجاري عصري مع شاشات LED (Mall LED Facade Design)

مشروع متكامل لتصميم واجهة معمارية عصرية لمول تجاري فاخر تدمج شاشات LED شفافة عالية الدقة مع محاكاة وتصورات ثلاثية الأبعاد (3D Interactive Simulation)، والالتزام بكود البناء السعودي (SBC 301 و SBC 306).

---

## 🚀 طريقة التشغيل والتثبيت
1. انسخ مجلد المشروع إلى المسار:
   `C:\xampp\htdocs\mall-led-project\`
2. شغّل خادم **Apache** وخادم **MySQL** من لوحة تحكم XAMPP Control Panel.
3. افتح رابط التثبيت لإنشاء قاعدة البيانات والجداول تلقائياً:
   👉 **http://localhost/mall-led-project/install.php**
4. بعد التثبيت بنجاح، يمكنك الوصول للصفحات:
   - **صفحة العرض والتصور 3D:** http://localhost/mall-led-project/index.html
   - **صفحة التحرير والإدارة:** http://localhost/mall-led-project/admin.html

---

## 🗄️ إعدادات قاعدة البيانات (MySQL)
- **اسم قاعدة البيانات:** `mall_led`
- **المضيف (Host):** `127.0.0.1` أو `localhost` (دعم منفذ 3306 و 3307)
- **المستخدم (User):** `root`
- **كلمة المرور (Pass):** (فارغة)
- **ترميز الحروف:** `utf8mb4_unicode_ci`

---

## 🏛️ المتطلبات الفنية والالتزام بكود البناء السعودي (SBC)
- **السطوع الأدنى للشاشات:** 6,500 Nit (ممتاز للرؤية تحت أشعة الشمس المباشرة)
- **معدل التحديث:** 3,840 Hz (خالي من الوميض والتصوير التلفزيوني)
- **درجة حماية الطقس:** IP65 Outdoor (مقاومة عالية للحرارة والأتربة والمطر)
- **نسبة التباين:** 40,000:1
- **الوصول للصيانة:** صيانة أمامية وخلفية مزدوجة (Front & Back Access)
- **الأكواد المعتمدة:** SBC 301 (الأحمال والقوى وحساب الرياح) و SBC 306 (كود ترشيد الطاقة)
- **العملة:** كل المبالغ بالريال السعودي (SAR).

---

## 🎨 المميزات والتصور ثلاثي الأبعاد (3D Features)
- **محاكاة 3D تفاعلية:** عرض مجسم 3D للمول والواجهة وشاشة LED على كافاس HTML5.
- **تبديل المشهد (نهار / ليل):** محاكاة الإضاءة المعمارية وانعكاسات الشاشة ليلاً ونهاراً.
- **التحكم بالسطوع والمنظور:** تدوير المنظور السمتي وسحب زاوية الرؤية وضبط سطوع الشاشة.
- **سجل الخبرة والأعمال المشابهة:** استعراض للمشاريع المنجزة سابقاً في الواجهات والشاشات الشفافة.
